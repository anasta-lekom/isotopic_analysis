# Веб-приложение для интерпретации изотопных данных нефтей с использованием методов машинного обучения

Веб-приложение предназначено для определения типа органического вещества и вторичных процессов
(термическое воздействие, окисление, биодеградация) в образцах жидких углеводородов
на основе изотопных данных δ¹³C с использованием методов машинного обучения.

---

## Описание проекта

Проект разработан в рамках выпускной квалификационной работы  
студентки 2М курса геологического ф-та МГУ Лекомцевой Анастасии Валерьевны  
и предназначен для автоматизации интерпретации изотопных данных нефтей и битумоидов.


---

## Функциональные возможности

- Ввод изотопных значений δ¹³C и визуализация изотопных кривых
- Классификация типа органического вещества по генезису
- Определение вторичных геохимических процессов:
  - термическое воздействие
  - окисление
  - биодеградация
  - миграция
- Определение связи нефть - кероген
- Пакетная обработка данных в формате .csv

---

## Используемые технологии

- **Backend**: FastAPI (Python)
- **Frontend**: React + Vite
- **Методы машинного обучения**: CatBoost
- **Контейнеризация**: Docker, Docker Compose

## Запуск программного комплекса

### Клонирование репозитория

```bash

cd lekomtseva_diplom
```
